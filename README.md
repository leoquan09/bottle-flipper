This is a socket.io and phaser game... The first one that I've made in so long. why is phaser so hard T^T.

Anyways, this as I mentioned before, this is a socket.io and phaser game that I made. Basically, it's a multiplayer game. The premise of this game is that you're trying to get everyone else with your bullet so that you are able to get more points (you score by hitting other people). It features a live updating leaderboard with everyone that is online and what I assume is basically real time updates of position and bullet position. Rather than sending bullet position each frame, I realized that you can just send the x, y, and the angle of the bullet and load it on the other peoples' screens so that it loads faster.

If you want to run this locally for some reason, you won't be able to connect to the same node server which means that I ASSUME that you won't be able to other players since they are on different web socket things. Anyways to run this locally all you have to do is fork the repository and then move into the server folder by running cd and then once you are in the folder you just run npm run dev. Quick side note that if you are running it locally for the first time, then you have to run npm i or npm install before running npm run dev so that you can have all the packages. If you don't like dev, then you can change it by locating the scripts in package.json in server and changing the dev key/value to what you want it to be.
